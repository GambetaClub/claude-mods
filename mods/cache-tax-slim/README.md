# cache-tax-slim

Keeps the one-hour prompt cache warm (costs tokens), warns before a cold send, and draws a status band above the prompt. Commands: `/keepwarm`, `/cache-tax`.

```
/plugin install cache-tax-slim --marketplace GambetaClub/claude-mods
```

Details and the other mods: [the repo README](../../README.md#cache-tax-slim). Slimmed from cache-tax by Karan Bansal, MIT.
